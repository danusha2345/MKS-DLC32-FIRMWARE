Сборка: feat/tmc2209-uart 24c65c8, дата 2026-07-31
Вариант: mks_dlc32_v2_1_tmc — TMC2209 по UART, БЕЗ экрана
Прошивка: Grbl_ESP32 1.1 (2022042101) + фиксы форка danusha2345
WebUI: ESP3D-WEBUI 2.1.3b0 (en/ru/uk/de/fr/es/it/pl/ptbr)
Плата: MKS DLC32 v2.1, ESP32-WROOM-32U, 8 МБ flash

!! ПРЕДРЕЛИЗ. На живом станке эта сборка не проверялась.
!! TMC2209 по UART требует навесной обвязки согласования уровней:
!! логика драйверов на плате пятивольтовая, ESP32 — 3.3 В.
!! Схема и номиналы: docs/TMC2209_UART.md. Без обвязки шина не заработает
!! (а RX напрямую способен повредить GPIO ESP32).

Новое в v2.1-tmc-beta2:
  - $Axis/Current/Run=0 больше не программирует максимальный ток
    (rms_current(0) давал CS=-1 -> 255 -> обрезка до 31, ~1.77 А RMS)
  - микрошаг принимается только из ряда 0/2/4/8/16/32/64/128/256
  - SENDDELAY=2 каждому драйверу при старте (требование даташита TMC2209
    для шины с несколькими слейвами)
  - SD-печать: слишком длинная строка или ошибка чтения больше не выдаются
    за успешное завершение ("SD Print Finish!"); задание закрывается с
    ошибкой и номером строки
  - устранена запись за границу буфера при строке ровно в 255 символов
  - read-only команды ($$, $+, $L, $S, $SC, $CMD) переведены на явный
    anyState вместо сломанного checker'а
  - документация: полный разбор уровней TMC2209 <-> DLC32 (docs/TMC2209_UART.md)

Новое в v2.1-tmc-beta1:
  Вариант прошивки с TMC2209 по UART: ток, микрошаг и StealthChop
  настраиваются командами ($X/Current/Run, $X/Current/Hold, $X/Microsteps),
  шаги идут как обычно через I2S. Экран не используется, coolant M7/M8
  недоступен (его пины заняты шиной).

Файлы:

  firmware.bin + spiffs.bin + bootloader/partitions/boot_app0
  flash_usb.sh / flash_usb.bat - прошивка с сохранением настроек
